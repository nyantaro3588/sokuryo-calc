# sokuryo-calc

座標法による面積計算、方向角・距離の逆算ツールを提供する無料HTMLツールです。

- 公開予定URL: https://nyantaro3588.github.io/sokuryo-calc/
- GitHub Pages: **Settings → Pages → Deploy from a branch → main / (root)**
- 入口ファイル: `index.html`
- サイトマップ: `sitemap.xml`
- 総合サイト: https://nyantaro3588.github.io/sokuryo/
- プライバシーポリシー: https://nyantaro3588.github.io/sokuryo/privacy.html

## 移行記録

`nyantaro3588/sokuryo/t2.html` を元に、独立サイト用の `index.html` に移植。
元のページは現在リンク互換性のため残してあります。新サイトの公開確認後、元ページは移転案内にする予定です。

計算フォームと計算ロジックは `index.html` 内にあります。計算機能を増やす場合は動作検証後に反映してください。
